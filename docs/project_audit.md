# Cortvex Project Audit

Cortvex is a premium digital agency website built with a modern React meta-framework, featuring interactive animations, dynamic components, and a database integration for user authentication and client meeting scheduling.

---

## 1. Core Technology Stack

- **Meta-Framework**: [TanStack Start](https://tanstack.com/router/latest/docs/start/overview) (React 19 + TypeScript)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) with a custom design system based on modern CSS tokens, gradients, and micro-animations
- **Database & Auth**: [Supabase](https://supabase.com/) (`@supabase/supabase-js`)
- **UI & Components**: Radix UI (packaged via shadcn/ui), Lucide React (icons), Recharts (charts), Embla Carousel
- **Scheduling**: Cal.com inline embed
- **Deployment Platform Target**: cPanel (via custom prerendering script) / Cloudflare Workers (Wrangler configuration ready)

## 3. Page Route Analysis

The application uses **TanStack Router** for file-based client-side routing. Below is a breakdown of the components defined in `src/routes/`:

### Root Layout (`src/routes/__root.tsx`)
- Configures global document metadata, canonical HTML tags, and styles.
- Wraps the entire route ecosystem in a TanStack Query `QueryClientProvider`.
- Exposes custom `NotFoundComponent` (404 page) and `ErrorComponent` to graceful handle rendering exceptions.

### Home Page (`src/routes/index.tsx`)
- **Hero Section**: Features a floating robot design overlaying dynamic background grids, rated star highlights, and navigation links.
- **Typing Animations**: Typewriter effect for section headings implemented via `useEffect` hooks.
- **Logos Marquees**: Inline horizontal infinite tickers (`logo-marquee-track-rtl` and `logo-marquee-track-ltr`) listing technology icons.
- **Why Choose Us & Services**: Grid of glassmorphic cards describing development, design, and AI capabilities.
- **Client Testimonials & Accordion FAQ**: Dynamic interactive sections.

### About Page (`src/routes/about.tsx`)
- Maps out agency details, target mission, and values.
- **Animated Counter Cards**: Interlocking `setInterval` counters that tick upwards from 1 to final counts (e.g., `20+ automations`, `80+ projects`) upon page entry.
- **Team Section**: A grid displaying staff members (Saif, Hassan, Umer, Husnain, Fariz, Areeba) in dark glass hover-cards with LinkedIn shortcuts.

### Services Page (`src/routes/services.tsx`)
- Exhaustive listing of agency categories (AI automation, web chatbots, voice bots, SEO, app development) with checkmarks highlighting standard deliverables.
- Custom anchors to scroll visitors directly to desired sections.

### Book Meeting (`src/routes/book-meeting.tsx`)
- **Access Guard**: Runs a `verifySession` call on component mount. Unauthenticated visitors are redirected to `/signin?mode=login`.
- **Form Submission**: Gathers details (name, email, company, budget, description), checkboxes for services, and a file attachment component.
- **Supabase Interaction**: Saves records across three distinct tables:
  1. Inserts core details into `meeting_bookings`.
  2. Map chosen capabilities in `meeting_booking_services`.
  3. Uploads files to storage bucket `meeting-docs` and catalogs them in `meeting_booking_documents`.
- **Inline Cal.com**: Loads `embed.js` dynamically post-submission and renders an inline calendar selector populated with the user's name/email.

### Sign-In Page (`src/routes/signin.tsx`)
- Provides login and registration tabs inside a glassmorphic container overlaid on a looping background video (`/hero-bg.mp4`).
- Interfaces directly with Supabase authentication (`supabase.auth.signInWithPassword` and `supabase.auth.signUp`).

## 4. Custom Deployment & Prerendering Pipeline

One of the project's most interesting components is `scripts/package-cpanel.mjs`, which compiles the dynamic TanStack Start server bundle and translates it into an SEO-optimized static site:

1. **Clear Directory**: Wipes and recreates the `cpanel-deploy/` target directory.
2. **Copy Assets**: Copies client-side bundles, assets, CSS, images, and fonts from `dist/client/`.
3. **Import Server Module**: Bootstraps the Cloudflare pages/Node-compatible bundle generated at `dist/server/index.js` at runtime.
4. **Static Generation**: Walks through defined routes (`/`, `/about`, `/blog`, `/book-meeting`, `/contact`, `/process`, `/services`, `/signin`, `/work`, `/sitemap.xml`), issues a mock `Request`, and writes the compiled HTML output to subdirectories containing a index.html (e.g. `cpanel-deploy/about/index.html`).
5. **Config Fallbacks**: Generates a custom `.htaccess` to handle Apache URL rewrites back to `index.html` so client-side routing behaves correctly on direct page hits.

This architecture achieves the best of both worlds:
- Fast initial loads and perfect SEO indexability (pages are static HTML).
- Smooth app-like client-side transitions (once loaded, client JS takes over routing).
- Simple, cheap hosting requirements (can be deployed straight to traditional Apache/cPanel static hosting).

## 5. Coding & Architecture Quality Observations

- **Modular Styling**: Standard styles are centralized in `src/styles.css` using custom tokens (`--brand`, `--radius`, `--gradient-brand`, `--shadow-soft`), minimizing Tailwind utility bloat in files.
- **Robust Exception Handling**: Custom middlewares in `src/start.ts` and error wrappers in `src/server.ts` isolate failures. The `consumeLastCapturedError` function pulls context before server responses are returned.
- **Supabase Design**: Relies on a robust, normalized database model (`meeting_bookings`, `meeting_booking_services`, and `meeting_booking_documents` with storage buckets).

### Recommendations / Potential Improvements
- **Contact Page Calendar Link**: In `src/routes/contact.tsx` (line 79), the "Open calendar" link currently references `href="#"`. It should link directly to the `/book-meeting` path to reuse the authenticated Cal.com booking flow.
- **Client Form Submission**: The form in `contact.tsx` currently updates a mock visual state (`setSent(true)`) but doesn't write to Supabase like the form in `book-meeting.tsx`. These entries could be piped to a `contact_submissions` table in Supabase.
